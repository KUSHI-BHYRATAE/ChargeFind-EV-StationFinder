2. WHAT WE ARE BUILDING
==================================================

Build a web application called:

CHARGEFIND

Tagline:

"Find the nearest EV charging stations intelligently."

The purpose of the application is:

A user provides a geographic location and asks for the K nearest EV charging stations.

The application uses:

1. A 2D KD-Tree for spatial indexing and nearest-neighbor searching.
2. Haversine distance for geographically accurate distance calculation.
3. Top-K nearest-neighbor search.
4. A real EV charging station dataset.
5. An interactive map to visualize the query location and nearby stations.

The application should demonstrate the DSA concepts underneath a polished real-world product.

The user should NOT need to understand the DSA to use the application.
